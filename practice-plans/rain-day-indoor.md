# Rain-Day Indoor Plan
**Length:** 75 minutes
**Focus:** Stick work, catching, and indoor 2-man game when the field is unusable.

Use the gym or hallway. No ground balls on a wet floor. No full-field transition.

## Schedule
| Time | Drill / Activity | Focus / Notes |
|---|---|---|
| 0:00 - 0:10 | Dynamic warmup | No line drills that need grass. Hip openers, shuffle, 10yd bursts. |
| 0:10 - 0:25 | [Elite Wall Ball Routine](../drills/stick-work/elite-wall-ball-routine.md) | Both hands. Tight box if the wall is shared. |
| 0:25 - 0:40 | [Catching Mechanics](../drills/stick-work/catching-mechanics.md) + [Cradling Mechanics](../drills/stick-work/cradling-mechanics.md) | Partner pairs. Soft hands first, then contact cradle in a 5yd box. |
| 0:40 - 0:55 | [3-Man Weave](../drills/3-man-weave.md) | Shorten the distance. Catch on the run, no bounce passes. |
| 0:55 - 1:10 | [Mastering the 2-Man Game](../offense/mastering-the-2-man-game.md) | Pick-and-pop in a half-gym box. Walk through, then live. |
| 1:10 - 1:15 | Breakdown | One cue for tomorrow if the field dries: first slide, first clear. |

## Do not run indoors
Ground-ball work, 6v6 half-field, and full-field rides. Save those for [Ground Ball Mechanics](../drills/stick-work/ground-ball-mechanics.md) and [Transition Focus Plan](transition-focus-plan.md) on a dry day.
